# IceMist Vape Website

## Project Overview

IceMist is a vape e-commerce website developed as a client project. The website was designed to showcase vape products, provide information about the business, and offer customers a simple shopping experience.

The project was discontinued after the client encountered resource constraints. The website remains available as a demonstration of my web development skills.

## Features

- Responsive website layout
- Product catalogue
- Shopping cart functionality
- About and Contact pages
- JavaScript-based product interactions

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Status

**Discontinued — Client project**

The project was not completed for launch due to the client's resource limitations. It is retained as a portfolio project to demonstrate front-end development and website design skills.

## Installation

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required for the front-end demonstration.
